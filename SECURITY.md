# Security Policy

This repository is intended to contain public front-end source only.

Do not commit:

- WordPress administrator credentials
- API keys or access tokens
- `.env` files
- `wp-config.php`
- Production database exports
- Customer information
- Payment information
- Private server or hosting credentials

If you discover a sensitive value in the repository, do not open a public issue containing the secret. Revoke or rotate the credential first and remove it from the repository/history as appropriate.
