# Contributing

Thanks for your interest in improving Auto Parts Trading.

## Workflow

1. Fork the repository.
2. Create a focused branch for your change.
3. Keep WordPress block comments and Gutenberg-compatible markup intact.
4. Test layouts at desktop, tablet and mobile widths.
5. Avoid committing credentials, private customer data, WordPress configuration files or production database exports.
6. Open a pull request with a concise description and screenshots for visual changes.

## Style

- Keep page-specific CSS scoped to the relevant component/page wrapper.
- Prefer semantic HTML.
- Preserve responsive behaviour.
- Keep public-facing text and links configurable where possible.
