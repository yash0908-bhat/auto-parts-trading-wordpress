# Project Structure

## `components/`

Reusable global WordPress template-part source.

### `header.html`
Custom automotive header with top utility links, branding, search, vehicle-registration CTA and primary navigation.

### `footer.html`
Reusable footer for company information, navigation and supporting site links.

## `pages/`

Page-level Gutenberg/HTML source.

### `home.html`
Main customer-facing homepage.

### `about.html`
Business/about page.

### `contact.html`
Contact page.

## `docs/`

Project documentation and portfolio screenshots.

This repository is intentionally source-focused. It is not a database dump or a complete WordPress installation.

## Visual references

`docs/screenshots/` contains design/reference previews. Third-party photography is documented in `docs/external-assets.md`. Interface icons are generally inline SVG and therefore already live inside the HTML source.
